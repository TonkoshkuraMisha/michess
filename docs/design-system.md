# Общие компоненты дизайна Regence

Решение владельца 18.11.2026: страницы выглядели «разрозненно и непрофессионально» — каждая собирала карточки, кнопки и
заголовки своими классами (основная кнопка повторялась 126 раз, тёмная панель — 120, карточка — 58). Теперь вид задают
общие компоненты `frontend/src/components/ui`, а страницы только собирают их. Витрина всех компонентов — страница
`/design` (в меню её нет).

## Компоненты

| Компонент | Когда |
|---|---|
| `Page` + `PageHeader` | Каждая страница. Ширина: `narrow` — чтение и списки (школа, правила), `default` — страницы с панелями (задачи, турниры), `wide` — доска с панелями (игровой зал, разбор). |
| `Section` | Раздел страницы с заголовком второго уровня и местом справа («Все», счётчик). |
| `Card`, `CardGrid` | Разделы, режимы, турниры, курсы. Вид `hero` — одна главная карточка на странице, `muted` — закрыто или «скоро». Карточка с `to` — целиком ссылка. |
| `Button`, `ButtonLink` | Действия. `primary` — **одно** главное действие на экране; `secondary` — обычные; `ghost` — второстепенные; `danger` — необратимые. |
| `SegmentedControl` | Режимы и фильтры одной строкой вместо россыпи одинаковых кнопок. |
| `Badge` | Состояние: `success` — пройдено, `accent` — текущее/новое, `danger` — закрыто/ошибка, `neutral` — справка. |
| `ProgressBar` | Прогресс «3 / 10», читается экранными читалками. |
| `EmptyState` | Пустой список: что здесь будет и одно действие. |

## Правила

1. **Одна главная кнопка на экране.** Остальные — `secondary` или `ghost`.
2. **Ритм отступов:** между блоками страницы 16 px (`gap-4`), внутри раздела 8 px (`gap-2`), внутри карточки 12 px.
3. **Шрифты:** заголовок страницы `text-2xl`, раздела `text-lg`, карточки — обычный жирный, пояснения `text-sm` с
   приглушённым цветом. Не больше одной строки пояснения под заголовком страницы.
4. **Сетка вместо длинного списка:** разделы и курсы — `CardGrid` (1 / 2 / 3 колонки), а не столбец широких карточек.
5. **Цвета — только через компоненты.** Новые оттенки не вводятся на странице; нужен новый вид — он добавляется в
   компонент, и меняется везде.
6. **Тексты — из каталогов трёх языков**, как везде (CLAUDE.md, правило 1).

## Порядок перевода страниц (план владельца 18.11)

1. Общие компоненты и витрина — этот шаг.
2. Задачи (сделано): до старта — карточки всех режимов по группам «Решать / Тренироваться / Свои партии» с
   описанием, выбранный — `hero` с кнопкой «Начать»; с задачей — те же группы вкладками `SegmentedControl`; у графика
   рейтинга подписаны оси. Группы и иконки — `components/puzzles/puzzleModes.ts`.
3. Школа и турниры: `CardGrid` с иконкой, прогрессом и «Продолжить»; «Большой курс» — `hero`.
4. Игровой зал: справа вкладки «Ходы / Чат / Наставник / Рентген» (сделано: предупреждение наставника открывает
   его вкладку само, у чата — число непрочитанных); дальше — доска по высоте окна и «Новая партия» по шагам.
