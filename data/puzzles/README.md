# Задачи

`lichess_subset.csv.gz` — выборка из открытой базы задач lichess (https://database.lichess.org/#puzzles),
лицензия **CC0** (общественное достояние). Отбор: `scripts/dev/build_puzzle_subset.py` — устойчивый рейтинг
(отклонение ≤ 80), популярность ≥ 85, не меньше 300 решений; рейтинг 600–2600 равномерно по корзинам в 100 пунктов
и квота на каждый тег, который реестр тем переводит в свою тему.

Колонки: `PuzzleId, FEN, Moves, Rating, RatingDeviation, Popularity, NbPlays, Themes` — как в исходной базе:
FEN — позиция до хода соперника, первый ход в `Moves` — ход соперника, дальше чередуются решение и ответы.

`lichess_themes_extra.csv.gz` — дополнение из той же базы (CC0) для тем без тегов lichess (таск 27.8): темы считают
распознаватели `src/services/theme_detectors.py` и классификатор матов, квота — нехватка темы до минимума ступени в
основной выборке. Сборка: `uv run --with zstandard python -m scripts.dev.build_theme_extra <база.csv.zst>`.

`endgame_generated.csv.gz` — свои задачи на эндшпильную технику (оппозиция, ключевые поля, обход, правило квадрата,
«не тот» слон): в открытой базе её почти нет. Позиции строит `scripts/dev/build_endgame_puzzles.py` и проверяет по
эндшпильным таблицам: задача берётся, только если верный ход ровно один. Формат тот же; тема — тег
`regence:<код реестра>`, в базе источник `regence` (до 19.11.2026 — `michess`; старые записи переименовала миграция). Сборка (нужна сеть, около часа):
`uv run python -m scripts.dev.build_endgame_puzzles`.

Загрузка в базу сервера: `python -m scripts.import_puzzles` (после миграций; повторный запуск безопасен).
