# Задачи

`lichess_subset.csv.gz` — выборка из открытой базы задач lichess (https://database.lichess.org/#puzzles),
лицензия **CC0** (общественное достояние). Отбор: `scripts/dev/build_puzzle_subset.py` — устойчивый рейтинг
(отклонение ≤ 80), популярность ≥ 85, не меньше 300 решений; рейтинг 600–2600 равномерно по корзинам в 100 пунктов
и квота на каждый тег, который реестр тем переводит в свою тему.

Колонки: `PuzzleId, FEN, Moves, Rating, RatingDeviation, Popularity, NbPlays, Themes` — как в исходной базе:
FEN — позиция до хода соперника, первый ход в `Moves` — ход соперника, дальше чередуются решение и ответы.

Загрузка в базу сервера: `python -m scripts.import_puzzles` (после миграций; повторный запуск безопасен).
