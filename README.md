# Michess ♟️ — шахматный клуб в браузере

Веб-платформа для игры и учёбы: партии с людьми и с ботами-историческими мастерами, арены и турниры, задачи и
тренажёры, школа и дебютный репертуар, разбор партий с наставником, библиотека партий и общение игроков. Интерфейс
на трёх языках — английском, украинском и русском. «Michess» — рабочее название; имя и домен выбирает владелец.

Как всё устроено внутри (что в каких файлах, откуда берутся данные, какими тестами проверяется) —
**[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**.

## 🚀 Что есть на сайте

**Игра**

* **Партии между людьми:** лобби с вызовами и автоподбор, приглашение по ссылке, рейтинговые и товарищеские партии,
  четыре категории контроля (пуля, блиц, рапид, классика) со своим рейтингом Эло в каждой, предходы, реванш,
  зрители и чат, фора, шахматы Фишера. Часы ведёт сервер; задержка сети возвращается игроку в пределах квоты.
* **Арены и швейцарки между людьми:** расписание по пяти конференциям мира, «последний старт» (каждая сыгранная
  партия засчитывается), допуск и группы по силе, берсерк, напоминания о начале. Очки игрока идут и в зачёт его
  конференции; раз в месяц — Кубок конференций.
* **Боты:** семь исторических мастеров XVIII–XIX веков, мастера конца XIX и XX века, участники знаменитых турниров прошлого и
  вымышленные архетипы; соперника можно собрать самому из ползунков характера. Сила ботов измерена матчами с
  эталонами Stockfish и показана как есть.
* **Клубная лестница, турниры с историческими мастерами и «Машина времени»** — знаменитые турниры прошлого, в
  которые игрок входит дополнительным участником.
* **Команды и сезонная лига.**

**Учёба**

* **Задачи:** по тактическим темам (реестр из 125 тем), на время, задача дня, задачи из собственных ошибок, защита,
  матовые конструкции, «Угадай ход мастера».
* **Школа и Большой курс:** азбука, уроки, классические партии с объяснениями, эндшпильный тренажёр, сверенный с
  эндшпильными таблицами, экзамены уровней, диагностика, программы тренировок, ежедневная разминка, карта навыков.
* **Тренажёры** зрения доски, памяти и счёта, игра вслепую, учебные мини-игры.
* **Дебюты:** справочник со статистикой партий и свой репертуар с повторением по расписанию.

**Разбор и просмотр**

* **Разбор партии** движком и **наставник**, который объясняет ходы словами и даёт подсказку по ступеням.
* **Библиотека партий**, архив чемпионов мира, «Просмотр» идущих партий, импорт своих партий с lichess и chess.com.

**Клуб**

* Подписки, уведомления, личные сообщения, лента публикаций, совместный разбор с тренером, достижения, модерация.
* Оформление: доски, наборы фигур, темы-комплекты, звуки; установка на телефон как приложения.

**Честность.** Во время своей рейтинговой партии игрок не получает от сервера оценок и ходов движка. Ритм ходов
анализирует античит; флаг ставит автоматика, а решение принимает модератор.

## 🛠 Технологии

| Часть | Чем сделано |
|---|---|
| Сервер | Python 3.14, FastAPI (HTTP и WebSocket), SQLAlchemy 2.0 + asyncpg, Alembic, Celery; пакеты — `uv` |
| Данные | PostgreSQL 16; Redis 7.4 (состояние идущих партий, лобби, лимиты, брокер Celery) |
| Шахматы | `python-chess`, Stockfish (только через пул процессов) |
| Клиент | React 19, TypeScript, Vite 6, Tailwind CSS v4, `chess.js`, `recharts`, `lucide-react` |
| Проверки | Pytest (2100+ тестов, без движка и сети), Ruff, mypy; Vitest (5500+ тестов), Oxlint, Playwright |

## 📦 Быстрый старт (разработка)

На ПК с Windows и Docker Desktop, из корня проекта:

    git clone https://github.com/TonkoshkuraMisha/michess.git michess
    cd michess
    git checkout dev
    .\start_dev.ps1

`start_dev.ps1` создаёт `.env` и окружение `.venv` (`uv sync`), скачивает Stockfish в `bin/`, ставит пакеты клиента,
поднимает PostgreSQL и Redis, применяет миграции, загружает задачи и открывает приложение:

* **Клиент:** http://127.0.0.1:3000
* **Описание API (Swagger):** http://127.0.0.1:8000/docs

Ручной запуск и проверки — `QUICKSTART.md`.
